# Порядок страниц при печати (режим `spread`)

Тетрадь **12 листов / 24 страницы**, снята со скоб, печать по **разворотам** (6 физических сгибов × 4 страницы).

Сборка G-code:

```bash
./scripts/build.sh pdfs/2.pdf output/notebook.gcode raster spread
# или
PDF_TO_PRINT_PAGE_ORDER=spread ./scripts/build.sh
```

В файле метки `;===== PAGE NN =====` — **номер страницы в тетради**, не порядковый номер шага.

См. также: [`pipeline.md`](pipeline.md) (техника), [`operator-manual.md`](operator-manual.md) §4.1 (workflow).

---

## Перед началом

| Момент | Действие |
|--------|----------|
| **Пауза 0** (после старта, до печати) | Установить UMTS с ручкой → Resume |
| Разворот 1 | Раскрыть **первый** физический лист (обложка), положить на стол |

## На каждой паузе «page flip» (шаги 1–23)

1. Открыть дверцу
2. Выставить **следующую** страницу из таблицы (подогнуть левую часть вниз — см. [`operator-manual.md`](operator-manual.md))
3. Проверить фиксацию по шаблону / магнитам
4. Закрыть дверцу → **Resume** на LCD

Перед паузой в G-code будет `;===== PAGE NN =====` — номер страницы, которую готовить к **следующему** шагу.

## Сводка по разворотам

| Разворот | Страницы подряд | Пауз между ними | После последней страницы |
|----------|-----------------|-----------------|---------------------------|
| 1 (обложка) | 1 → 2 → 23 → 24 | 3 | сменить разворот |
| 2 | 3 → 4 → 21 → 22 | 3 | сменить разворот |
| 3 | 5 → 6 → 19 → 20 | 3 | сменить разворот |
| 4 | 7 → 8 → 17 → 18 | 3 | сменить разворот |
| 5 | 9 → 10 → 15 → 16 | 3 | сменить разворот |
| 6 (середина) | 11 → 12 → 13 → 14 | 3 | финал: снять модуль |

**Итого:** 24 печати, **23** паузы перелистывания + 1 пауза установки модуля + 1 финальная.

## Режим `sequential` (по умолчанию)

Обычная сборка `./scripts/build.sh` — тетрадь **сложена**, листаем 1 → 2 → … → 24, без привязки к разворотам. Таблица выше **не** применяется.
