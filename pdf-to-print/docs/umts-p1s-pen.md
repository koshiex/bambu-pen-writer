# UMTS — Инструкция для Bambu Lab P1S (рисование ручкой)

Модульная система для плоттера на базе принтера P1S. Поддерживаемые ручки: Stabilo, POSCA.

## ⚠️ Безопасность (обязательно)

Модуль устанавливается внутрь закрытого корпуса P1S. Неверный offset или некорректные границы могут привести к столкновению со:

- внутренними стенками / рамой
- передней дверцей / верхним стеклом
- вентиляторами / кожухами
- печатной головой

Правила:

- Изучить X/Y/Z offset перед изменением значений. Не понимаешь — не трогай.
- Перед каждым запуском проверить безопасную зону (использовать шаблон).
- Держать модуль подальше от стенок и особенно от верхнего стекла.
- Если стекло ограничивает ход пружины — снять его или поднять райзером.
- Не менять компенсации, защищённые зоны, исключённую область вслепую.
- При столкновении немедленно выключить принтер.

## Слайсер

Использовать **Orca Slicer в режиме LAN ONLY** — только в этом режиме корректно обрабатывается Z-компенсация.

## Подготовка изображения

Конвертировать рисунок/фото в SVG через Convertio → Export as SVG.

Почему SVG: слайсер интерпретирует напрямую, геометрия чистая. JPG/PNG дают грязные или избыточно тяжёлые штрихи.

## Исключённая область (P1S)

Скопировать значение в настройки принтера:

```
( 0x0, 258x0, 258x55, 48x55, 48x258, 0x258 )
```

Не менять без полного понимания границ движения модуля.

## Положение бумаги

Кончик ручки не совпадает с соплом, поэтому бумагу класть с фиксированным отступом:

- от правой стенки (X): **29 мм**
- от задней стенки (Y): **41 мм**

Рекомендуется напечатать направляющую с этими отступами:

1. положить направляющую на стол
2. выровнять
3. заменить чистым листом
4. центрирование стабильно повторяется

## Ширина рабочей зоны = A4 (210 мм)

Технически возможно больше, но ограничение 210 мм даёт:

- кнопка «Center» в слайсере центрирует рисунок по A4
- без ручной правки offset
- без замеров «на глаз»

## Настройки принтера

### 1) Z-Offset

Printer Settings → Machine → Z-offset:

- **+17.0 мм** для Stabilo
- **+20.0 мм** для POSCA

Смысл: «не опускайся так низко, как думаешь» — ручка свисает ниже держателя.

### 2) Вентиляция (всё OFF)

- Part cooling fan: 0%
- Aux fan: 0%
- Chamber fan: 0%

Причина: вентиляторы дают вибрации и поток воздуха → бумагу сдвигает, давление ручки скачет, линии волнистые.

### 3) Retraction + Z-hop (обязательно)

Отключить всё, кроме:

- Retraction: **0.01 мм** (разблокирует Z-hop в Bambu/Orca)

Затем:

- Z-hop: **3 мм**
- Z-hop angle: **90° / Normal**

Без Z-hop ручка тащит чернила во время travel-движений → паразитные линии.

## Конфигурация ручек

### Stabilo

Оранжевый кончик торчит ~0.5 мм (едва видно). Давление контролируется пружиной + глубиной посадки + Z-offset.

### POSCA

Перевернуть направляющую + узел верхней пружины, затянуть винты так, чтобы тыльная часть POSCA упиралась в стол.

Зачем: постоянная физическая опора → стабильное давление → чистые линии.

## Профиль филамента (plotter mode) — ОБЯЗАТЕЛЬНО

Прошивка не позволяет полностью отключить экструзию, поэтому:

- Nozzle: **180 °C** (предотвращает ошибку cold extrusion prevention)
- Bed: минимум (1°C если разрешает, иначе 25°C)
- Chamber/standby/soften: 0°C если разрешает, иначе минимум
- Flow ratio: **0.01** (экструдер не толкает материал, но система активна)
- Max volumetric speed: **22 mm³/s**
- Ventilation: всё OFF

Минимальная температура стола → бумага не расширяется и не деформируется.

## Настройки печати

### Слой

- Height: 0.10 мм
- First layer: 0.10 мм

### Ширина линий

- Все: **0.40 мм** (под Stabilo)
- Для большей точности — поменять сопло и пересчитать значения соответствующе

### Геометрия

- Closing radius: 0.001
- Resolution: 0.012
- XY Hole Compensation: −0.075
- XY Contour Compensation: +0.075
- Perimeters: 1
- Infill: Rectilinear aligned (если нужны заливки)

### Скорость

- Stabilo: **300–400 мм/с**
- POSCA: **30–40 мм/с**

## Процесс печати

### 1) Подготовка файла в слайсере

- Импортировать STL шаблона/детали в Orca Slicer
- Разместить в нужной ориентации
- Проверить:
  - центрирование
  - не заходит в исключённую область
- Сверить инструмент ↔ профиль (Stabilo / POSCA)

### 2) Положить бумагу

Отступы: 29 мм (X) от правой стенки, 41 мм (Y) от задней. Гарантирует:

- ручка не уходит за край листа
- не заходит в опасные зоны

### 3) Подготовить «безопасную паузу» для установки модуля

Конфигурация:

- 6–8 начальных слоёв по 0.10 мм
- паузы в конце всех слоёв, включая слой 0

Что происходит внутри:

- первая линия печатается на Z = 0 (сопло на столе)
- затем автоматический подъём на компенсированную высоту (Z-offset)
- дальше работа стабильна

➡️ Только после этого момента безопасно ставить UMTS.

### 4) Установка UMTS во время безопасной паузы

Два варианта:

- **A (консервативный)**: дождаться окончания слоя → автоматическая пауза → установить
- **B (быстрый)**: увидел работу на компенсированной высоте → ручная пауза → установить

### 5) Как ставить UMTS

- В паузе перейти в ручное движение
- Подвести голову в доступную зону
- Установить модуль
- Проверить:
  - правильно собран
  - не касается стекла
  - пружина имеет свободный ход
  - offset корректный

### 6) Снять UMTS в конце (критично)

На последней паузе:

- Пауза → ручное движение головы
- Аккуратно снять модуль
- Убедиться, что всё чисто
- Остановить печать

**НИКОГДА не давать принтеру завершить последний слой с установленным модулем** — он решит, что печать закончена, и попытается обрезать филамент → столкновение.

## Тестовые фазы (особенно при первом запуске)

Снижают риск почти до нуля.

### Phase 2 — пустая голова, только база

- Старт пустой головой
- Пауза → установить базу
- Resume → «фантомное» рисование
- Финальная пауза → снять базу

### Phase 3 — полная сборка без ручки

- Старт пустой
- Пауза → база + пружина + направляющая
- Resume → проверить столкновения
- Финальная пауза → снять сборку

### Phase 4 — живая калибровка с ручкой

- Бумага зафиксирована по отступам
- Старт пустой
- Пауза → полная сборка
- Вставить ручку с запасом по высоте (менее выдвинуто)
- Resume и подстройка вживую:

Цикл:

- пауза → опустить на 1–2 мм → resume
- пока:
  - рисует чисто
  - и поднимается во время travel

## Калибровка Z

### Метод 1: живая подстройка (рекомендуется в первый раз)

- ✅ Мгновенный фидбек, не нужно резать
- ❌ Требует ручной правки при смене инструмента/ручки

### Метод 2: правка Z-offset в профиле (для повторяемости)

- давит слишком сильно → увеличить offset (17.0 → 17.5)
- не касается / очень бледно → уменьшить offset (17.0 → 16.5)
- Save → trim → repeat

**ПРИ СТОЛКНОВЕНИИ — НЕМЕДЛЕННО ВЫКЛЮЧИТЬ.**

## Диагностика по симптомам

| Симптом | Причина / решение |
|---|---|
| Бледные линии или нет рисунка | Нет контакта → уменьшить offset или вставить ручку глубже |
| Давит сильно / чернила размазаны | Избыточное давление → увеличить offset или вытащить ручку |
| Тащит чернила во время travel | Z-hop недостаточен или выключен → Normal + 3–4 мм |
| Больше 50 слоёв в SVG | Разблокировать uniform scale + SVG Z = 0.1 мм |
| Паузы и продолжения сами | Пропущен M400 U1 |
| Игнорирует тонкие линии | Arachne + wall min ≈ 0.2 мм |
